# Smart-Library-Management-System

To collab on github, download cmder from this website: https://cmder.app/

Necessary commands (cmder):
cd : move to the file you want e.g. cd C:Users/Documents or cd .. to move back
dir : show all files you can move to
git clone : to download the codes into PC
git add . : save all the changes
git commit -m "message" : to tell other about the changes you made
git remote -v  : check all the branch you have
git push origin <branch_name> : upload the changes to the website
git pull origin <branch_name> : download the changes from website to ur PC
git checkout -b <branch_name> : create a new branch

Normal procedure:
1) Go to the website repository
2) Copy the link
3) Go to the cmder type "git clone "
4) Go to your coding platform
5) git checkout -b <branch_name>
6) Write your code
7) git add .
8) git commit -m "added "
9) git push origin <branch_name>
